# aseri

Nine public signals of geopolitical risk, forecast every day with Mistral's Timestral, each with its range and its own track record.

**[exdsgift.github.io/aseri](https://exdsgift.github.io/aseri/)**

![Screenshot: page at 1440 px, 1440x900](branding/screenshots/page-1440.png)

- **Daily, by itself.** A GitHub Action fetches nine public series at 07:00 UTC, forecasts them with Timestral-209M on CPU and publishes a static page.
- **Scored in public.** Every forecast is archived append-only and scored against what happened. Backtests are labelled and never mixed into the live record.
- **Data you can use.** The forecasts are a public JSON API in the Hubverse format: [exdsgift.github.io/aseri/api](https://exdsgift.github.io/aseri/api/).
